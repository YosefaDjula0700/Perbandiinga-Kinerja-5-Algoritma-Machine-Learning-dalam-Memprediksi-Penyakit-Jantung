# Perbandiinga-Kinerja-5-Algoritma-Machine-Learning-dalam-Memprediksi-Penyakit-Jantung
Proyek ini merupakan aplikasi web interaktif yang dikembangkan menggunakan Streamlit, dirancang khusus untuk memfasilitasi analisis mendalam dan komparatif terhadap lima algoritma Machine Learning utama dalam klasifikasi risiko penyakit jantung.
